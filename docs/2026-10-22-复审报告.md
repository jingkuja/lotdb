**行为变化（需要知晓）：**
- MySQL `TINYINT(1)` / `BOOLEAN` 显示为 0/1，不再是 true/false；`BIT(n)` 显示为数字。
- MySQL 会话改用服务器时区，TIMESTAMP 显示的是服务器本地时间（与 Navicat、mysql CLI 一致）。
- 导出或传输遇到无法无损表示的列，会报错并停止，不再静默写入"(不支持的类型)"。
- 已知限制：PG 的二进制协议路径（表格浏览、带参数的查询）仍无法解码少数类型（tsvector、range、几何类型、domain 等），表格里会显示占位文本；导出和传输不受影响。

**行为变化：**
- 勾选"导入前清空表"（CSV/JSON）后，导入是全有或全无：任何一行失败都会回滚，表保持原样。

## 2. P1（已于 2026-10-24 修复，见 1b 节；以下保留原始描述）

### 2.1 数据安全 / 资源

1. **SSH 隧道泄漏**：`src-tauri/src/db/ssh_tunnel.rs:18`。`AbortHandle` 被 drop 时不会终止任务，监听循环又持有 session 的 Arc，所以每次断开、重连、"测试连接"都会留下一个 SSH 会话和一个 127.0.0.1 上的监听端口，本机任何进程都能经这个端口连到远端库。
   - 建议：为 `SshTunnel` 实现 `Drop`，调用 `abort()` 并断开 session。
2. **SSH 密码明文落盘**：`src-tauri/src/commands/connection.rs:18`。`SshConfig` 整体序列化进 SQLite，包括 SSH 密码和口令；`get_connections` 也会把它返回给前端。
   - 建议：SSH 密码也存 Keychain，SQLite 只保存非敏感字段。
3. **mysqldump 的密码出现在进程参数里**：`src-tauri/src/commands/backup.rs:163`（恢复在 `:334` 附近）。`ps` 能看到。
   - 建议：改用 `MYSQL_PWD` 环境变量，或 `--defaults-extra-file` 配合权限为 0600 的临时文件。
4. **用户管理拼接 SQL**：`src-tauri/src/commands/admin.rs:275` 等。密码含 `'` 会失败，含 `\` 时 MySQL 会按转义处理，实际存下的密码和用户输入不一致；用户名、库名也没有转义。`run_truncate`、恢复时的 `CREATE DATABASE`、建库时的 charset 同样有这个问题。
   - 建议：统一改用 `quote_ident_*` 和 `string_literal`。

### 2.2 功能错误

5. **MySQL"活跃查询"页必定报错**：`admin.rs:435`。`PROCESSLIST.ID` 是 BIGINT UNSIGNED，代码按 `i64` 解码，实测报 mismatched types。改用 `u64`，或在 SQL 里 `CAST(id AS SIGNED)`。
6. **表设计器会丢数据**：`src/lib/generate-ddl.ts:234`。
   - 列按名字匹配，改列名会生成 `DROP COLUMN` + `ADD COLUMN`，整列数据丢失。应该用列的 `id` 跟踪重命名，生成 `RENAME COLUMN` / `CHANGE COLUMN`。
   - MySQL 的 `MODIFY COLUMN`（`:265`）会重建整列定义，丢掉 `ON UPDATE CURRENT_TIMESTAMP`、列排序规则、生成列等设计器没有建模的属性。
   - "结构对比"生成的同步 SQL 也有同样的问题。
7. **导入**：`src-tauri/src/commands/transfer.rs` 中的 `import_table_data_impl`。
   - 先 TRUNCATE（`:1263`）再逐行插入，没有事务，也不能取消；列映射填错时，表已经被清空了。
   - 每行插入都要一次预处理往返，远程导入大文件非常慢。建议参照传输功能，按 500 行批量插入、每批一个事务。
   - "浏览…"只拿到文件名，拿不到路径（`src/components/transfer/import-dialog.tsx:171`）。建议接入 `tauri-plugin-dialog` 的 open/save。
8. **导出连接配置不生效**：`src/components/connection/import-export-connections-dialog.tsx:50`。wry 在没有下载处理器时会取消 `<a download>`，所以不会生成文件，界面却提示成功。另外 `:44` 只清空了数据库密码，修好后会把 SSH 密码一起导出。
9. **批量导出整表读进内存**：`transfer.rs` 中的 `batch_export_tables`，大表会导致内存暴涨（单表导出本身是流式的）。
10. **结果行数上限只限制显示**：PG 会读完剩余所有行再丢弃（`src-tauri/src/commands/query.rs:707`），MySQL 在执行下一条语句前也要把剩余行读完。所以 `SELECT * FROM 大表` 照样会传输整张表。
    - 建议：截断后对 MySQL `KILL QUERY` 或丢弃该连接；PG 用游标或带 max_rows 的 portal。
11. **PG 管理功能：**
    - 表大小 SQL 没给表名加引号（`admin.rs:692`），库里有 `"User"` 这类大小写表名时整页报错（已实测）。另外 `get_table_sizes` 走主连接池，忽略了所选数据库。
    - 复合外键显示成笛卡尔积（`src-tauri/src/commands/schema.rs:569`），实测 2 列外键返回 4 行。应改为 `unnest(conkey, confkey) WITH ORDINALITY`。
    - 删库时，LotDB 自己缓存的子连接池可能还占着该库，导致 `DROP DATABASE` 失败。
12. **SSH**：加密私钥无法使用（`ssh_tunnel.rs:48` 没有用到 passphrase，界面上也没有输入框）；没有心跳和超时设置。
13. **备份/恢复**：psql 恢复忽略退出码（`backup.rs:407`），部分失败也显示成功（建议加 `-v ON_ERROR_STOP=1`）；不可取消，没有进度；同步调用 `Command::output()`。
14. **查询切换 schema**：`SET search_path TO schema`（`query.rs:999`）把 `public` 也去掉了，`public` 里的扩展函数会找不到。

## 4. 功能缺失（已于 2026-10-24 补齐，见 1d 节；以下保留原始描述）

- 对象树上没有删表、清空表、重命名表、复制表结构、删视图/函数的入口。
- 表格不能选中单元格、不能用 Cmd+C 复制，不能用方向键导航，没有右键菜单（复制值、设为 NULL、按此值筛选、删除行）。
- 列宽固定 140px，不能按内容自适应，日期时间会被截断。
- 没有系统原生的文件选择和保存对话框（导入、导出、备份、恢复都要手动输入路径）。
- PG 没有新建数据库入口（后端支持，前端只给了 MySQL）。
- EXPLAIN 只有表格或纯文本，没有图形化执行计划。
- 结构对比只能单表对单表，不能整库对比。
- 对象树内没有过滤框；系统库（information_schema、mysql、sys 等）和业务库混在一起排列。
- 导出 CSV 没有"带 BOM"选项（Excel 打开中文会乱码）；导入不支持 GBK 编码；CSV 导入无法区分空字符串和 NULL。
- 导入不可取消，传输进度没有总数和 ETA。

## 5. UI 问题（已于 2026-10-24 修复，见 1e 节；以下保留原始描述）

**合理的部分：**
- 侧栏 + 标签 + 内容区的布局清晰。
- 连接对话框（常规 / SSH / SSL）干净。
- NULL 和空字符串区分明显。
- 标签上显示连接和数据库上下文。
- 深浅色主题完整。
- 本轮新增的确认/输入对话框风格与其他对话框统一。

**待改进：**
1. **查询页工具栏过载**：在 1280 宽的窗口下折成两行，有十几个控件。
   - 常驻的提示文字、没开事务时也显示的"提交/回滚事务"、和标签重复的连接徽标都可以去掉。
   - Explain 和 Analyze 用的是同一个图标，"片段"和"书签+"是两个书签图标。
2. **结果区上方叠了两条栏**（统计栏和复制/导出栏），可以合并。
3. **表数据页：**
   - 常驻一行操作说明，建议改为首次提示或 tooltip。
   - 新增行的每个单元格有 N、D、E 三个字母按钮，含义不直观。
   - 统计完总数后，"总数已统计"按钮仍占位置。
4. **侧栏顶部 9 个无文字图标**挤在 260px 里，连接级、应用级、对象级的操作混在一起。主题、快捷键、设置可以收进一个菜单。
5. **大量操作只在鼠标悬停时出现**：连接行 4 个、数据库行 3 个、"数据库"标题行 6 个管理入口。可发现性差；删除按钮紧挨编辑和恢复，容易误点。建议改为右键菜单。
6. **交互不一致**：单击表打开数据，单击视图打开 DDL；双击表会打开两个标签。
7. **语言混杂**：对象树显示 Tables / Views / Functions / Triggers，其他地方是中文。
8. **首页**：没有最近记录时，会留下一个空的边框卡片。
9. **关闭非空查询标签每次都要确认**：对象是草稿，频繁打扰。可以考虑"关闭即保留到历史"，或只在有未执行修改时提示。
