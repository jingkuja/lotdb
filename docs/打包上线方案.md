# LotDB 打包上线方案

> 适用产品：LotDB（Tauri v2 + React，macOS 桌面端，MySQL / PostgreSQL 客户端）
> 文档日期：2026-08-29
> 目标产物：已公证的 `LotDB.app` + `LotDB_x.y.z_aarch64.dmg`（可选 Universal）

本文同时给出 **当前能不能用** 的结论，以及 **怎么打成可分发给别人的安装包**。

---

## 0. 一句话结论

| 场景 | 结论 |
|------|------|
| 开发者本机日常使用（`pnpm tauri dev` / 本地 `tauri build`） | **可以正常使用**。连接、浏览、查询、改表、导入导出、备份恢复等主路径已接通。 |
| 打成 DMG 给别人双击安装 | **还不能作为正式上线包**。本机没有 Apple 签名证书，未做公证；未签名的 `.app` 会被 Gatekeeper 拦截。 |
| 对外正式发布（官网 / GitHub Release） | **差签名公证 + 若干发布前修补**，见第 3 节。 |

功能规格（`plan.md` Phase 0–11）除「DMG 签名公证」和「自动更新」外，均已落地。未提交的 `transfer.rs` 改动应一并带上：PostgreSQL 导入/导出/跨库传输会按所选数据库建池，而不是连默认库。

2. 权宜：在 `eslint.config.js` 把 `react-hooks/set-state-in-effect` / `react-hooks/preserve-manual-memoization` 降为 `warn`，先让流水线过。

### 1.3 代码层缺陷（不挡自己用，对外要心里有数）

| 级别 | 问题 | 位置 / 说明 |
|------|------|-------------|
| P0 体验 | 本地 SQLite 异步 `manage`，启动瞬间前端 `get_connections` 可能碰到「state not managed」 | `src-tauri/src/lib.rs` `setup` 里 `spawn` 初始化。React Query 会重试，多数时候能缓过来，冷启动仍可能闪错。应改为在 `setup` 里 `block_on` 完成后再 `manage`。 |
| P1 正确性 | 未提交：PG 导入/导出/传输未切到用户选的数据库 | 工作区已改 `transfer.rs` 的 `resolve_pool`，**打包前请提交**。 |
| P1 安全 | SSH 隧道接受任意主机密钥 | `ssh_tunnel.rs`：`check_server_key` 恒 `Ok(true)`，有 MITM 风险。 |
| P1 安全 | 导入/传输把单元格拼进 SQL 字符串 | `transfer.rs` 用转义后的字面量 `INSERT`，不是参数绑定。单元格含未覆盖的转义序列时有注入面。日常自用风险低，对外应改为 bind。 |
| P1 安全 | 导出 `WHERE` 是原始拼接 | 用户输入直接进 SQL。仅限本机已授权连接，但仍应视为「高级 SQL 片段」而不是过滤器。 |
| P2 | 版本号三处不一致 | `package.json` = `1.0.0`；`Cargo.toml` / `tauri.conf.json` = `0.1.0`。Finder「关于」显示的是 **tauri.conf.json**。 |
| P2 | `tauri-plugin-sql` 已依赖并 preload，前端未使用 | 实际元数据走 `local_store.rs` 自己的 SQLite。多余依赖，可上线后删。 |
| P2 | `csp: null` | 桌面 WebView 可接受，正式发布建议补一条收紧的 CSP。 |
| P2 | plan 勾了「多窗口」「E2E / Playwright」 | 代码里没有 `WebviewWindow`，也没有 Playwright。属于文档超前，不是运行时 bug。 |
| P3 | 标识符 quoting 未转义内部 `` ` `` / `"` | 表名含引号时 DDL/导出 SQL 会坏。极罕见。 |

集成测试本次 **未连真实 MySQL/PG 跑**（本机未设置 `LOTDB_TEST_*`）。CI 有覆盖，本地发布前建议跑一遍：

```bash

export LOTDB_TEST_PG_URL=postgres://user:密码@127.0.0.1:5432/postgres
cd src-tauri && cargo test
```

## 2. 功能维度检查

对照 `plan.md` 功能规格，按「自己能不能完成一次真实工作」评估。

### 2.1 可以正常使用

| 模块 | 状态 | 说明 |
|------|------|------|
| 连接管理 | 可用 | MySQL / PG，SSH 隧道（密码/密钥），SSL，分组，测试连接，Keychain 存密，连接导入导出（不含密码） |
| 对象树 | 可用 | 库 → Schema(PG) → 表/视图/函数/触发器/序列/枚举 |
| 表结构 | 可用 | 列 / 索引 / 外键 |
| 对象搜索 / 补全 | 可用 | ⌘K 搜索；编辑器表名列名补全 |
| SQL 编辑器 | 可用 | 高亮、格式化、选中执行、多语句拆分、结果截断、取消查询、历史、片段、参数绑定、EXPLAIN |
| 数据网格 | 可用 | 分页排序筛选、行内编辑、增删、变更预览、NULL、单元格查看器、复制为 INSERT/CSV/JSON/Markdown |
| 表设计器 | 可用 | 可视化建表/改表、索引/外键、DDL 预览与对比 |
| 导入导出 | 可用 | 导出 CSV/JSON/SQL/Excel；导入 CSV/JSON/SQL；批量导出；进度事件 |
| 跨连接传输 | 可用 | 列映射、可选清空、WHERE/LIMIT（请带上 `transfer.rs` 的 PG 路由修复） |
| 库管理 | 可用 | 建删库、用户权限（基础）、进程列表/KILL、磁盘占用、结构 diff |
| 备份恢复 | 条件可用 | 调用本机 `mysqldump` / `pg_dump` / `mysql` / `psql`。没有客户端工具会明确报错 |
| 主题 / 快捷键 / 偏好 / 最近 | 可用 | 深浅色、快捷键帮助、字体字号、最近标签 |

### 2.2 规格里有、体验不完整（不挡主路径）

| 项 | 现状 |
|----|------|
| 原生文件选择器 | 导入/导出/备份路径是文本框（会预填「下载」目录）。没有 `tauri-plugin-dialog`，「浏览…」体验弱。 |
| 视图 / 函数 | 只能看 DDL，并通过「编辑执行」丢进查询页。没有独立的可视化创建向导。 |
| 触发器 | 浏览、看 DDL、删除。创建走 SQL 编辑器。 |
| SQL 编辑器切库 | 查询跑在连接打开时的默认库。MySQL 可 `USE db` / `` `db`.`t` ``；PG 必须在连接配置里填对 database，或另开一条连接。 |
| 多窗口 | 未实现。单窗口多标签够用。 |
| 备份 | 依赖系统 PATH / Homebrew 客户端，不内置 dump。分发说明里必须写清楚。 |
| 只读连接 | 已在 `execute_query` / `execute_statements` 拦截 DML/DDL。 |

### 2.3 主路径（建议发布前人工点一遍）

1. 新建 MySQL 连接 → 测试 → 打开 → 展开对象树。
2. 打开一张表数据 → 改一格 → 预览 SQL → 提交；新增/删除一行。
3. 新建查询 → `SELECT` → 看截断提示；跑一条慢查询点「停止」。
4. 表设计器改一列 → DDL 预览 → 执行。
5. 导出 CSV 到「下载」；再导入回去。
6. 若本机有 `mysqldump`：备份一个小库再恢复到测试库。
7. PostgreSQL 重复 1–5，并验证：**连接默认库 A，对象树点进库 B 做导出/导入**（依赖未提交的 `resolve_pool`）。
8. 打开只读连接，确认 UPDATE 被拒绝。
9. 断网或停数据库，确认结果区出现「重新连接」。

## 4. 版本与元数据

打包时以 `src-tauri/tauri.conf.json` 的 `version` 为准。建议三处对齐：

```
package.json                 "version": "1.0.0"
src-tauri/Cargo.toml         version = "1.0.0"
src-tauri/tauri.conf.json    "version": "1.0.0"
```

建议补全的 `tauri.conf.json` 字段（示例，按实际改）：

```json
{
  "productName": "LotDB",
  "version": "1.0.0",
  "identifier": "com.lotdb.app",
  "bundle": {
    "active": true,
    "targets": ["app", "dmg"],
    "category": "public.app-category.developer-tools",
    "shortDescription": "轻量 MySQL / PostgreSQL 管理工具",
    "longDescription": "LotDB 是面向 macOS 的轻量数据库客户端，支持连接管理、SQL 编辑、表设计、导入导出与备份恢复。",
    "copyright": "Copyright © 2026 LotDB",
    "macOS": {
      "minimumSystemVersion": "12.0",
      "hardenedRuntime": true,
      "signingIdentity": "Developer ID Application: 你的名字 (TEAMID)",
      "entitlements": "entitlements.plist"
    }
  }
}
```

`identifier` 已是 `com.lotdb.app`，与 Keychain service 名一致，**不要改**。改了以后老用户钥匙串里的密码会全部读不到。

## 6. 本地构建（未签名，仅自己用）

环境：macOS 12+、Apple Silicon（本机 `arm64`）、Node 22、pnpm 10、Rust stable、Xcode 或 CLT。

```bash
# 1. 依赖
pnpm install --frozen-lockfile

# 2. 质量门（发布前应全绿）
pnpm lint
npx tsc -b
pnpm test
cd src-tauri && cargo fmt --check && cargo clippy -- -D warnings && cargo test --lib && cd ..

# 3. 打 macOS .app + .dmg（未签名）
pnpm package
# 等价：pnpm tauri build

# 产物
# src-tauri/target/release/bundle/macos/LotDB.app
# src-tauri/target/release/bundle/dmg/LotDB_1.0.0_aarch64.dmg

# 4. 打开
pnpm open:app
```

未签名包给别人时，对方会看到「无法验证开发者」。变通：右键 → 打开 → 仍要打开。这只适合发给自己或极小范围测试，**不能当上线包**。

当前仓库里 `src-tauri/target/release/bundle/macos/` 是空目录，需要重新 `pnpm package`。

### 6.1 备份功能的运行时依赖

LotDB **不内嵌** dump 引擎。用户机器需要：

```bash
brew install mysql-client postgresql@16
# 确认
which mysqldump mysql pg_dump psql
```

Release 说明和官网 FAQ 必须写这一条。

### 6.2 Universal（Intel + Apple Silicon）

只在 M 系列本机构建得到 `aarch64`。若要同时支持 Intel：

```bash
rustup target add x86_64-apple-darwin
pnpm tauri build --target universal-apple-darwin
```

耗时约 ×2，公证对象变成 Universal `.app`。建议 1.0 若用户几乎全是 Apple Silicon，可先发 `aarch64`，Intel 需求出现再补。

## 7. 代码签名与公证（对外上线的硬门槛）

macOS 对外分发标准路径：**Developer ID 签名 → 上传公证 → staple 票据 → 再打 DMG**。

### 7.1 账号与证书

1. 加入 [Apple Developer Program](https://developer.apple.com/programs/)。
2. 在开发者后台创建 **Developer ID Application** 证书（公证分发用这个，不是 Mac App Store 的 `Apple Distribution`）。
3. 下载并导入登录钥匙串。验证：

```bash
security find-identity -v -p codesigning
# 应出现：Developer ID Application: Your Name (TEAMID)
```

4. 创建 App 专用密码（appleid.apple.com → 登录与安全），或改用 App Store Connect API Key（CI 更稳）。

### 7.2 Entitlements

新建 `src-tauri/entitlements.plist`（**不要开 App Sandbox**，除非以后上 Mac App Store）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>com.apple.security.cs.allow-jit</key>
  <true/>
  <key>com.apple.security.network.client</key>
  <true/>
  <key>com.apple.security.files.user-selected.read-write</key>
  <true/>
</dict>
</plist>
```

- `network.client`：连远端 MySQL/PG/SSH。
- `user-selected.read-write`：导入导出备份文件。
- `allow-jit`：WKWebView 常见需要。若公证时报 JIT 相关失败再确认，不要无故加 `disable-library-validation`。

Keychain 访问自己写入的 `com.lotdb.app` 通用密码，非沙盒 Developer ID 应用不需要额外 Keychain 组。

### 7.3 本机签名 + 公证

把身份填进 `tauri.conf.json` 的 `bundle.macOS.signingIdentity` 后：

```bash
export APPLE_ID="you@example.com"
export APPLE_PASSWORD="app-specific-password"   # 或改用 API Key
export APPLE_TEAM_ID="XXXXXXXXXX"
export APPLE_SIGNING_IDENTITY="Developer ID Application: Your Name (TEAMID)"

pnpm tauri build
```

Tauri 2 在能取到上述变量时会：签名 `.app` → `notarytool submit` → 等待 Accepted → staple。

手动补救（Tauri 没自动公证成功时）：

```bash
APP="src-tauri/target/release/bundle/macos/LotDB.app"
codesign --verify --deep --strict --verbose=2 "$APP"
spctl --assess --type execute -v "$APP"

xcrun notarytool submit src-tauri/target/release/bundle/dmg/*.dmg \
  --apple-id "$APPLE_ID" --team-id "$APPLE_TEAM_ID" --password "$APPLE_PASSWORD" --wait

xcrun stapler staple "$APP"
xcrun stapler staple src-tauri/target/release/bundle/dmg/*.dmg
```

验收标准：把 DMG 拷到一台 **从未打开过 Xcode、未关 Gatekeeper** 的 Mac，双击安装后能直接启动，没有「已损坏 / 无法验证开发者」。

### 7.4 不要做的事

- 不要用 ad-hoc 签名（`signingIdentity: "-"`）对外发。
- 不要把 `.p12` / App 专用密码提交进 git。只放 GitHub Actions secrets。
- 不要先上 Mac App Store：要沙盒、IAP 条款、网络/文件权限重做，和工作室分发不是同一条路。

## 8. GitHub Actions 发布流水线

现有 `.github/workflows/ci.yml` 只做 PR 检查，**没有 release job**。建议新增 `.github/workflows/release.yml`：

```yaml
name: Release

on:
  push:
    tags: ["v*"]

jobs:
  release:
    runs-on: macos-14
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile

      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: aarch64-apple-darwin

      - uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri

      - name: Quality gates
        run: |
          pnpm lint
          npx tsc -b
          pnpm test

      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
          APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
          APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_PASSWORD: ${{ secrets.APPLE_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
        with:
          tagName: ${{ github.ref_name }}
          releaseName: "LotDB ${{ github.ref_name }}"
          releaseBody: |
            macOS 12+ / Apple Silicon
            备份/恢复需要本机安装 mysql-client 与 postgresql 客户端。
          releaseDraft: true
          prerelease: false
```

仓库 Secrets 最少 6 个：

| Secret | 内容 |
|--------|------|
| `APPLE_CERTIFICATE` | Developer ID `.p12` 的 base64 |
| `APPLE_CERTIFICATE_PASSWORD` | p12 密码 |
| `APPLE_SIGNING_IDENTITY` | `Developer ID Application: … (TEAMID)` |
| `APPLE_ID` | Apple ID 邮箱 |
| `APPLE_PASSWORD` | App 专用密码 |
| `APPLE_TEAM_ID` | 10 位 Team ID |

发布操作：

```bash
# 版本已改成 1.0.0 并 push 到 main
git tag v1.0.0
git push origin v1.0.0
```

流水线打出 draft Release，人工下载 DMG 在干净 Mac 上点一遍第 2.3 节，再点 Publish。

## 10. 上线之后（不进 1.0）

| 项 | 做法 |
|----|------|
| 自动更新 | `tauri-plugin-updater` + 签名的 `latest.json`。需要单独的 updater 密钥，和 Apple 公证是两件事。 |
| 崩溃收集 | 可选 Sentry native；注意 SQL 与连接串不要上报。 |
| 遥测 | 默认关闭。若做，必须明示且可关。 |
| 多窗口 | Tauri `WebviewWindow`，能力列表里的 `windows` 要从 `["main"]` 放宽。 |
| Windows / Linux | 架构可移植，但 Keychain 在非 macOS 是 stub，要换系统凭证库。 |
